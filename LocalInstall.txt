1. Clone & Navigate

Clone the repository and move into the project folder:

2. Install Dependencies

Run the standard installation command to install all required packages listed in the package.json file:
in CMD on the project folder:
"npm install"

3. Handle the .env File

If the project uses environment variables (like database credentials or API keys):

    Look for a .env.example file in the project root.

    Copy and rename it to exactly .env.

    Open it and fill in your local configuration values.
